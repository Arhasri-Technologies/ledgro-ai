PLANNED PRODUCT WORKFLOW
Inside the VEL.ai architecture PLANNED CAPABILITIES

Continuity by design

Persist project state across refreshes, restarts, and provider interruptions. Inspect and preserve existing architecture. Reuse blueprints and version agents, skills, and policies for each run.

Permissions before execution

Workspace entitlements define available capabilities. A saved configuration does not grant execution rights. Human and agent permissions are checked separately; server policy resolves credentials and resource access.

Evidence before completion

Plan, validate, approve, execute, persist, verify, and audit. Generated code enters quality checks. Keep structured results, approved summaries, and evidence—not raw model reasoning.

Controlled local execution

VEL Electron is intended to support approved work with project files, Git, Nx, builds, browsers, and selected desktop tools through scoped permissions.

Connected development

Coordinate task dependencies, Cursor execution, and GitHub branches, commits, and pull requests. Carry build, test, security, and visual evidence into preview and release decisions.

Governed growth

Manage provider accounts, quotas, health, usage, and workspace bindings. Improve reusable skills through controlled, versioned changes.
