# Planet carousel artwork

Created with the built-in image generation tool. These are generated photographic-style visualizations, not spacecraft photographs.

Workspace assets: `apps/web/public/assets/venus-realistic.png` and `apps/web/public/assets/mars-realistic.png`.

## Venus

Use case: photorealistic-natural. Asset type: realistic planet cutout for a premium website carousel. Create a single Venus sphere, a highly detailed NASA-style photographic visualization, perfectly circular, centered, fully visible, filling precisely 96% of a square canvas, transparent background. Venus has dense cream, pale ochre and warm ivory cloud cover with intricate natural swirling wisps and atmospheric bands, NOT striped like Jupiter, no visible rocky terrain. Soft directional sunlight from upper left with realistic subtle spherical shading, most of disk illuminated so details remain readable. Clean sharp limb. No halo, no outer glow, no rays, no stars, no backdrop, no text, no framing, no other objects. High resolution surface detail; restrained natural colors.
